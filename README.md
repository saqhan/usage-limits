# usage-limits

Мод для Claude Code: лимиты подписки Claude всегда видны в строке статуса под полем ввода, без кликов.

```
usage-limits  5ч 48% до 00:50 · нед 45% до 16:00
```

- `5ч` — пятичасовое окно, `нед` — недельное; после `до` — когда окно сбросится (дальше суток — с днём недели).
- От 80% перед лимитом появляется ⚠.
- Цифры обновляются сами после каждого ответа. До первого ответа в новой сессии строки нет.
- Работает в терминале и в Code-вкладке настольного приложения Claude.

Shows your Claude 5-hour and weekly usage limits in the status line under the prompt.

## Установка

```
/plugin install usage-limits --marketplace saqhan/usage-limits
```

Ответить `y` на добавление маркетплейса, затем выбрать область (user — для всех проектов).
